macOSで『エターナルリターン』やHoYoverseのゲームを楽しむために特化したランチャーです。

**使用中にアカウントが停止された場合や、ランク戦中にゲームがクラッシュした場合でも、開発者は責任を負いません（とても重要）。**

<p align="center">
  <img width="200" src="../../resouces/docs/Saddy.jpg"/>
</p>

<p align="center">
  <b>注意事項</b><br>
  Steamをインストールできても、すべてのSteamゲームが動作するとは限りません。<br>
  現在、起動を保証しているSteamゲームは<b>『エターナルリターン』のみ</b>です。<br>
  CodeWeavers CrossOverの使用を強く推奨します。<br>
  このランチャーの主な目的は、レンダリングや視覚効果の崩れを防ぐことです。<br>
</p>

# 主な機能

- 点滅や正しく描画されない視覚効果を修正します。
- Wine、DXMT、Bottle、Prefix、ゲームランチャー、起動オプションをまとめて管理します。
- Stable、Beta、Nightlyのアップデートチャンネルに対応しています。

## 『崩壊：スターレイル』のグラフィック設定

DXMTでゲームを実行する場合は、ゲーム内の**ライティング品質**を**中**に設定してください。**高**または**最高**に設定すると、ライティングのちらつきやその他のレンダリング不具合が発生することがあります。

## WineとDXMTの提供元

[Custom CrossOver builds](https://github.com/Bob-Ddong-Iri-Hoyo/fullbodied-anca-wine-house)
: このランチャー向けにメンテナンスされているCrossOverベースのカスタムWineビルドです。Wine 11およびCrossOver 26.0.0以降をベースにしています。

[Official Wine](https://www.winehq.org/)
: Wineの公式プロジェクトです。

[DXMT](https://github.com/3Shain/dxmt)
: Metalを直接利用するDirect3D 11変換レイヤーです。

## 参考資料

Wineランタイムとランチャーの開発時に参照したプロジェクトと資料：

[CodeWeavers](https://www.codeweavers.com/)
: CrossOverを開発している企業です。

[Gcenx Wine](https://github.com/Gcenx/macOS_Wine_builds)
: GcenxがメンテナンスしているmacOS向けWineビルドです。

[YAAGL](https://github.com/yaagl/yet-another-anime-game-launcher)
: macOS向けのHoYoverseゲームランチャーです。

[MacPorts Wine](https://github.com/riverfog7/macports-wine)
: YAAGLで使用されていると考えられるWineパッチセットです。

[Anime Game Launcher](https://github.com/an-anime-team/an-anime-game-launcher)
: Linux向けのHoYoverseゲームランチャーです。

[Dawn Winery](https://dawn.wine/dawn-winery)
: アニメ調ゲーム向けのWineビルドとパッチです。

[Proton](https://github.com/valvesoftware/proton)
: Valveが開発しているWineベースの互換ツールです。

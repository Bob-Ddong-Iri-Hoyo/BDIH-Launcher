# Renderer Components

Renderer 공용 UI 컴포넌트별 변경 지시서 모음이다.

이 폴더의 md 파일을 수정하면 해당 컴포넌트의 UI 요구사항으로 사용한다.

대표 파일:

- `LogViewer.md`: App 로그와 Bottle 실행 로그를 보는 화면 컴포넌트.
- `MainFrame.md`: 앱 shell, sidebar, header, content frame.
- `BottleCard.md`, `DashboardHomePanel.md`, `BottleDetailPanel.md`: Bottle dashboard 구성요소.
- `Dialog.md`, `ContextMenu.md`: overlay 계열 공용 UI.
- `SelectMenu.md`, `IconButton.md`, `StatusBadge.md`, `ProgressBar.md`: 작은 재사용 UI.

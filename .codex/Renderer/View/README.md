# Renderer Views

Renderer View와 App container별 변경 지시서 모음이다.

이 폴더의 md 파일은 화면 조립, 라우팅, container/store 연결, 전체 레이아웃 변경에 사용한다.

대표 파일:

- `LauncherView.md`: MainFrame 안에서 dashboard/logs/preferences를 전환하는 최상위 화면 조립.
- `DashboardView.md`: Bottle home/detail, context menu, create dialog를 관리하는 dashboard view.
- `PreferenceView.md`: 설정 화면 본체.
- `SplashView.md`: 로딩 화면 본체.
- `TerminalView.md`: terminal window container.
